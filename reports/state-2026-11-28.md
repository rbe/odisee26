## 1. Summary

Odisee is a web service. It fills a LibreOffice template from an XML or JSON request. Odisee returns the document in the response, writes the document to a bucket, or produces the document in a background job. In the classes that this report names, the author found no break of the 7 accepted ADRs. `make project-report` lists at least one test for each ADR. No publish has run yet, because the repository has no version tag and no GitHub release. Four decisions wait for you.

## 7. Decisions for you

1. How long does Odisee keep the files of a job? Row: [W-14](../docs/ROADMAP.md#w-14) (How long does Odisee keep the job files?).
   - Now: Odisee keeps them until someone deletes them by hand. The author did not open `odictl`, so the author does not know whether a command deletes them. Objects in a bucket are a separate rule in [ADR-0006](../docs/adr/ADR-0006.md) (Delivery, jobs, and callbacks stay per user) and are not part of this question.
   - Option A, keep them as now. Effect: no code changes. The disk use grows with each job.
   - Option B, delete them after a fixed number of days, for example 7. Effect: the disk holds at most 7 days of job files. A client must fetch the file within 7 days.
   - Option C, delete them after the first successful `GET /document/jobs/{id}`. Effect: the disk holds only files that no client fetched. A second fetch returns no file.
   - Recommendation: option B. If the first fetch fails, the client can then still try again.
2. Does CI run all 6 gates? Row: [W-15](../docs/ROADMAP.md#w-15) (Does CI run all six gates?).
   - Now: CI runs `make test` and `make test-java`. The GitHub runner already has Podman, because `test-java` passed in run 38.
   - Option A, add `make editorconfig`, `make format`, `make lint`, and `make coverage` to `ci.yml`. Effect: CI matches the rule. Each CI run takes longer. The author did not measure by how many minutes.
   - Option B, keep CI as it is and write a divergence line in `docs/pipeline-rules.md`. The rule itself is in `rules.md` of RalfSkills. Effect: CI does not change. Only the pre-push hook checks formatting and lint.
   - Recommendation: option A. If a push comes from a machine without the pre-push hook, CI then still finds a format or lint error.
3. Which macro language and macro location may a request name? Row: [W-16](../docs/ROADMAP.md#w-16) (Which macro language and location may a request name?). The answer also closes [W-1](../docs/ROADMAP.md#w-1) (stricter allow-list for names).
   - Now: a request can name any language, such as `Basic` (the macro language of LibreOffice) or `Python`. It can name any macro location, such as `document`, `application`, `user`, or `share`.
   - In this repository, the sample requests, the clients, and the documentation name only `language=Basic`. Only one test names `location=application`. Status: read. Source: a search for `language=` and `location=` in `webservice/src/main/container/var`, `clients`, `documentation`, and `webservice/src/test`. The author cannot see the templates on your servers.
   - Option A, only `Basic` in `document`. Effect: a request can run only Basic macros that are inside its own template. A request that names another language or location then gets HTTP 400. If a template on your servers calls an `application` macro, that template stops working.
   - Option B, `Basic` in `document` and in `application`. Effect: a request can also run the Basic libraries of the office instance. A request that names `user`, `share`, or another language gets HTTP 400.
   - Option C, any value, as now. Effect: no code changes. Each user can start any script that LibreOffice installed.
   - Recommendation: option A. Each script that a request can run is then inside a template that the user stored.
4. When does the first publish happen? Row: [W-17](../docs/ROADMAP.md#w-17) (When does the first publish happen?).
   - Now: `build.gradle.kts` sets the project version `2.6.0` for local builds. A publish needs the git tag `v2.6.0`. The published version is then `2.6.0-<run number>`. You start a publish by hand from the Actions tab, or set `AUTO_PUBLISH` to `true`.

   - Option B, publish after you answer decision 3 and an agent fixes [W-1](../docs/ROADMAP.md#w-1) (stricter allow-list for names) and [W-18](../docs/ROADMAP.md#w-18) (error bodies show internal messages). Effect: until then, a person cannot install Odisee from GitHub. The author did not estimate the time of these fixes.
   - Recommendation: option B. The fix of [W-1](../docs/ROADMAP.md#w-1) limits which scripts a logged-in client can run. The fix of [W-18](../docs/ROADMAP.md#w-18) limits what an error response shows.
