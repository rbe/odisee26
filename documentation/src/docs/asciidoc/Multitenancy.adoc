[[multitenancy]]
Multitenancy
~~~~~~~~~~~~

A logged-in user has a private directory under `$ODISEE_HOME/var/user/{name}/`.
Templates are in `template`.
Merge inputs are in `work`.
Generated files are in `output`.
The job list is `jobs.json` in that same directory.
There is no shared `var/template` fallback.

[[adding-odisee-users]]
Adding Odisee Users
^^^^^^^^^^^^^^^^^^^

`odictl user NAME` creates the Keycloak user and a confidential client whose id is `NAME`.
It also creates `template`, `work`, and `output` under `var/user/NAME/`.
It prints the client id and secret.
Odisee does not store the secret.
`java -jar` does not read `odisee-users.xml`.
A bad name fails.
An existing user fails.
The person who can run `odictl` is the admin.

[[permissions]]
Permissions
~~~~~~~~~~~

`etc/oidc` is readable by the server user.
`odictl user` writes the issuer and audience there.
This server does not configure SFTP.

[[access-to-http-service]]
Access to HTTP Service
^^^^^^^^^^^^^^^^^^^^^^

`POST /odisee/document/generate` and `POST /odisee/document/jobs` accept `Authorization: Bearer`.
The token's issuer and audience must match `$ODISEE_HOME/etc/oidc`.
An API client's id is the Odisee user.
A username claim on that token does not select a different user.
The UI client `odisee-ui` uses `preferred_username`.
No login is HTTP 401 and does not generate a document.
Any authenticated user may run macros.
The macro name, library, and language must be plain names.
A bad name is HTTP 400.
`GET /odisee/ready` stays anonymous.
The Keycloak compose service is in the administrators guide, <<machine-login>>.

[[callback-hosts]]
Callback hosts
^^^^^^^^^^^^^^

`POST /odisee/document/jobs?callback=https://host/path` stores that URL on the job.
Odisee POSTs only when that host is listed for that user in `$ODISEE_HOME/etc/callback-hosts`.
One line is `username host`.
`odictl callback-host USER HOST` appends a line.
A host listed for one user does not allow another user's callback.
A URL whose host is off that user's list does not get a POST.
`POST /odisee/document/generate` does not read a callback.
